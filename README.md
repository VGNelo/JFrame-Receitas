# JFrame Receitas
Projeto simples em Java Swing para treinar GUI.

## Estrutura
- `src/` → código fonte (`ReceitasFrame.java`)
- `bin/` → arquivos compilados (`ReceitasFrame.class`)
- `.gitignore` → ignora arquivos compilados

## Como executar
javac -d bin src/ReceitasFrame.java
java -cp bin ReceitasFrame
